# Orientación a Objetos 2

Este repositorio contiene prácticas y teóricos de la materia Orientación a Objetos 2.

## Contenido
### Año 2026 (`2026/`)

* **[Práctica](2026/Práctica/)**: ejercicios prácticos resueltos en Java.
    * **[Parciales](2026/Práctica/Parciales/)**: parciales resueltos (BurgerOO2, EnvioDePaquetes, OO2Music, OO2SmartHome).
    * **[Patrones](2026/Práctica/Patrones/)**: ejercicios de patrones de diseño (AlquilerAutos, Calculadora, DecodificadorPeliculas, DispositivoMovilYConexiones, Excursiones, FileSystem, Friday13, GenealogiaSalvaje, GestionDeportiva, JuegosDeRol, MediaPlayer, Mensajero, PlanesMedicos, PrestamosPrendarios, ProductosFinancieros, SubteWay, Sueldos, ToDoItem, Topografias, ejercicio23, filters-pipes, filtros).
    * **[Refactoring](2026/Práctica/Refactoring/)**: ejercicios de refactoring (Empleados, FacturacionLlamadas, Iteradores-Circulares, Productos, TrianguloRectangulo). Incluye `Cuadernillo resuelto.pdf`.
    * **[Frameworks](2026/Práctica/Frameworks/)**: ejercicios de frameworks (JavaLogging, SingleThreadTCPServer, StreamBeacons).
    * **[Repaso-Twitter](2026/Práctica/Repaso-Twitter/)**: ejercicio integrador de repaso.
* **[Teoría](2026/Teoría/)**: diapositivas de las clases teóricas (catálogo de code smells, refactoring, entre otros).
